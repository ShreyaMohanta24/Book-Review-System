# 📚 Book Review System

A Java-based, menu-driven **Book Review System** for managing users, books, ratings, and reviews.

## Features

- 👤 Register and display users
- 📖 Add and display books
- 🔎 Search for books
- 🔤 Sort books alphabetically using Merge Sort
- ⭐ Display top-rated books
- 📝 Add, display, and delete reviews

## 🛠️ Technologies Used

- Java
- OOP
- Data Structures and Algorithms
- ArrayList
- Merge Sort

2. Open the project in a Java IDE such as VS Code, IntelliJ IDEA, or Eclipse.
3. Run `src/Main.java`.
